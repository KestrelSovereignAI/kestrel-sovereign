Parallel Tracks Are Possible

Claws finishing touches and Talon hardening can run in parallel (Phase 1). Eye and Flight are sequential — Eye's runner must exist before Flight can orchestrate visual validation. But Eye development can start as soon as Talon produces PRs to review.

Phase 1 — Claws Completion + Agent Mesh Protocol

Owner: Gabi + Noel · Repo: kestrel-sovereign, signal-and-ship

Finish the PM bird so it can autonomously manage the backlog, enforce quality, and hand off work to Talon.

  • Backlog Constitution (signal-and-ship #2) — Rules engine that grades issues. Rejects vague items, auto-labels, suggests improvements. Uses Constitution articles as quality standard.
  • Agent Mesh Protocol (signal-and-ship #3) — Define the message format for bird-to-bird communication: {from: "claws", to: "talon", type: "assign", issue: 42, priority: "high"}. Implement as Python dataclass + async queue on Sovereign.

07. Recommended Starting Point

Based on current state and dependencies, here's the critical path for the first real deliverable: Claws assigns work to Talon through Agent Mesh.

First Milestone: "Claws assigns, Talon delivers"

This is the minimum viable Falconer loop. Claws runs Morning Signal, identifies the top issue, sends an Agent Mesh message to Talon, and Talon claims it, codes it, and opens a PR. No Eye review, no Flight reporting — just the PM → Developer handoff. Once this loop runs end-to-end for one falconer (Gabi), you have the proof point for everything else.

Sprint Zero — Prove the Loop

Owner: Gabi · Deliverable: One complete Claws → Talon cycle
  • Step 1: Define Agent Mesh message schema (Python dataclass, simple JSON over internal API)
  • Step 2: Add /mesh/send and /mesh/receive endpoints to Sovereign
  • Step 3: Claws Morning Signal outputs a "top pick" + sends mesh message to Talon agent
  • Step 4: Talon agent receives message, runs kestrel-talon claim on the issue
  • Step 5: Talon reports back via mesh: "PR #X opened for issue #Y"
  • Step 6: Claws logs it in STRATEGY.yaml and next Morning Signal shows the completed loop

This is 6 concrete steps. Step 1-2 are the infrastructure. Steps 3-6 are wiring existing code together. Most of the code already exists — Morning Signal generates priorities, Talon claims issues. The only new code is the mesh endpoints and the wire between them.
