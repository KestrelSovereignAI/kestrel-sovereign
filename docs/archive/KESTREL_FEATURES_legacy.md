# Kestrel Sovereign Legacy Feature Catalog

> Historical snapshot of the pre-canonical feature catalog.
>
> This file is preserved for historical context only. It is not the maintained source of truth.
> The maintained canonical inventory is [`KESTREL_FEATURES.md`](../../KESTREL_FEATURES.md).

## Why This File Exists

- The previous catalog mixed real implementation detail with stale fixed counts.
- It presented numbers such as `69 REST endpoints` and `28 feature plugins` that no longer matched the live code surface.
- It was also used as the input for audience-specific generated docs, which meant drift propagated downstream.

## Historical Characteristics Of The Legacy Catalog

- It used a "Complete Feature Catalog" framing.
- It treated hardcoded counts as durable truth.
- It blended maintained surfaces, aspirational surfaces, and implementation snapshots in one document.
