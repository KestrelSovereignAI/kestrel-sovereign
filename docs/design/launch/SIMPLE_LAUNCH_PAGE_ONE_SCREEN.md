# Kestrel Simple Launch Page: One-Screen Version

Use this if the team wants a single-screen launch page with minimal implementation overhead.

## Goal

Make the first screen do all essential jobs:

- hook the reader
- explain Kestrel in one breath
- show why it matters
- establish proof
- send the user to the quickstart or repo

## One-Screen Copy

### Eyebrow

The open foundation for Sovereign AI

### Headline

Own your AI.

### Subheadline

Kestrel is the open foundation for Sovereign AI: identity, memory, privacy, and governance that belong to the user, not the platform.

### Body copy

Most AI today is rented intelligence. The model may help you, but the durable layers still belong to someone else. Kestrel gives developers a way to build agents with portable identity, persistent memory, and constitutional governance enforced above the model.

Already used in a real clinical setting, Kestrel is designed for teams that need continuity, accountability, and user ownership rather than another provider-controlled wrapper.

Inspect the repo
