# 0.66.9 — Native MCP Task controls

- Govern Task input updates and cancellations through the original tool
  registration, operator permission and durable effect journal. Retain the
  original cancellation request across retries.
- Deliver Task status, input and final results through the original authenticated
  chat or physical App View. Preserve output-schema checks and the original
  required dispatch audit.
- Recover a pending Task from durable storage in a new process, under its original
  OAuth grant.
- Record an elapsed Task retention window locally when a server polling hint
  extends beyond it. Keep the original remote outcome unknown.
- Update the visual worker lock to match the Core 0.66.9 wheel.

These changes support private [MCP Task composition](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/3684).
Public activation also requires the
[official Python MCP SDK fix](https://github.com/modelcontextprotocol/python-sdk/issues/3866).
