# Core 0.53.27

Named `kestrel start <name>` launches now direct child output to the agent's
append-only log file. The launcher may exit after readiness without losing
later log lines or racing a daemon stdout pump during interpreter shutdown.
Persistent supervisors keep their existing log-and-host-stdout pump. Process
identity, A2A transport custody, readiness and termination rules are unchanged.
Windows children receive native append-only handles rather than relying on
parent-only CRT append flags. The real-child output probe runs against the
installed package in every clean-install OS/method axis.

This patch carries the reviewed native constitution-publication and transaction
custody work merged for 0.53.26. That tag's publication was blocked by the macOS
wheel launcher failure, so 0.53.26 was not uploaded to PyPI. Its tag is retained
unchanged; 0.53.27 must pass the complete release and cross-platform install gates.
