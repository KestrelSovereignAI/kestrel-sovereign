# v0.47.0 — Fail-Closed Constitution Integrity

> **⚠️ Read this BEFORE upgrading a deployment from ≤ 0.46.2.** This release
> ships fail-closed constitution integrity enforcement. An agent whose
> governance anchors have drifted — even if it ran fine on 0.46.x — will enter
> **constitution safe mode at first boot** after the upgrade, and the
> reachability-gated `/health` endpoint will report 503 until the drift is
> remediated, so `kestrel start` appears to hang and then times out.

## What changed (fail-closed behavior)

- **Genesis-audit lifecycle** (#2600): cognition is hard-gated on a durable
  `passed` genesis-audit receipt bound to the governing constitution hash.
- **Durable safe mode** (#2595): a constitution integrity failure now places
  the agent in safe mode that **survives restarts** — rebooting does not clear
  it; only `!safe-mode exit` after remediation does.
- **Integrity proofs** (#2463): the periodic and boot-time audit now proves,
  and fails closed on:
  1. the anchored constitution blob is retrievable, decryptable, and hashes
     to the anchor (`constitution_hash`);
  2. the `agent --governed_by--> constitution` graph edge exists **and
     targets the anchored hash**;
  3. the anchor matches the resolver-rendered authoritative governing source
     (including any active Amendment VIII emancipation contract);
  4. any per-agent `CONSTITUTION.md` overlay is anchored
     (`constitution_overlay_hash`) and unmodified, and an anchored overlay
     still exists on disk (#1722).

Legacy state that silently passed on 0.46.x fails these proofs. The
2026-07-18 production incident that motivated this note (#2616) hit exactly
that: three agents whose `constitution_hash` property had been updated by a
historical pre-atomic reanchor while the `governed_by` edge still pointed at
an ancient anchor (proof 2), and one agent anchored on an ancient
constitution with an unanchored overlay.

## Pre-upgrade check: `kestrel doctor`

`kestrel doctor` now performs a per-agent **anchor-drift check** covering the
same conditions the fail-closed audit enforces:

- `constitution_hash` property vs `governed_by` edge target agreement
  (proof 2);
- anchored hash vs the resolver-rendered governing source;
- overlay anchoring (present ⇒ anchored and unmodified; anchored ⇒ present).

Run it from the **upgraded checkout/package before restarting your agents**
(doctor only reads the agent DBs; it never writes):

```bash
kestrel doctor
```

Every agent should report ✅ for the constitution lines. Any ❌ names the
drifted agent, the mismatching hashes, and the exact remediation command.
Remediate all drift **before** starting agents on this version — otherwise
they boot straight into safe mode.

## Reanchor runbook

Full ceremony detail:
[`docs/architecture/security/SOVEREIGN_TRUST_ROOT.md`](../architecture/security/SOVEREIGN_TRUST_ROOT.md).
Condensed sequence:

1. **Trust-root setup** (one-time per operator). Store one public Sovereign
   DID document as JSON in an operator-controlled location **outside** any
   agent database, and point the runtime at it:

   ```bash
   export KESTREL_SOVEREIGN_TRUST_ROOT_PATH=/secure/sovereign-root.did.json
   ```

   The database being protected never supplies its own verification key;
   missing, ambiguous, or agent-owned roots fail closed.

2. **Sign a reanchor artifact.** Compute the SHA-256 of the exact governing
   constitution bytes produced by the canonical resolver (including any
   active emancipation contract), create a `kestrel.constitution.reanchor.v1`
   detached artifact for that hash, and sign it with the private key matching
   the pinned DID document.

3. **Reanchor each drifted agent** (agent stopped; the DB is backed up
   first):

   ```bash
   kestrel constitution reanchor \
     --agent-name <Name> \
     --force \
     --signed-artifact /secure/constitution-reanchor.signed.json \
     --trust-root /secure/sovereign-root.did.json
   ```

   Without `--force` the command only reports drift and writes nothing. The
   reanchor updates all governance locations atomically — blob, document
   node, `constitution_hash` property, `governed_by` edge, and RAG chunks —
   which is what repairs the edge-only drift shape from the incident.

4. **Anchor overlays** for any agent with a per-agent `CONSTITUTION.md`
   (agent stopped):

   ```bash
   kestrel constitution anchor-overlay --agent-name <Name>
   ```

5. **Restart and exit safe mode.** Reanchor never exits safe mode
   automatically. If an agent already tripped the enforcement, start it and
   run `!safe-mode exit` after verifying the audit passes.
