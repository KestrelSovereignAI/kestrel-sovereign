# 0.66.2 — incremental co-hosted native HTTP

Candidate release notes; publication/deployment and downstream acceptance
remain separate gates for [#4016](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4016).

- Add `NativeA2APublication.inprocess_http_transport(app)`, retaining the exact
  published recipient, ordinary signed SDK codec, proof/authorization guards
  and original ASGI middleware. There is no network fallback or alternate
  protocol implementation.
- Deliver headers, initial and progress events before task completion with
  bounded canonical callback-source backpressure. HTTPX read/write deadlines
  apply to actual I/O rather than being ignored by a buffering ASGI adapter.
- Join one original application/source close task across cancellation and
  overlapping close observers. Finite slow-cleanup observations retain private
  debt; they do not manufacture successful retirement or erase original errors.
- Use ASGI2.0 disconnect for cooperative middleware shutdown, rather than a
  private exception injected through task groups. Reuse the canonical response
  close owner and compose transport context-exit errors, so a cleanup deadline
  cannot erase the original body-read, revocation or caller-cancellation error.
- Retain the ingress route scope independently of Starlette's mounted dispatch
  mutations, and remove physically settled failed exchanges from pending work.
- Harvest original source-owner outcomes independently of the close task, so
  failed close-task admission cannot erase later physical cleanup failures.
- Keep HTTP reads finite during concurrent close by borrowing terminal
  observation, without cancelling original cleanup or changing the shared
  iterator's default physical must-join contract.
- Preserve streaming uploads and streamed replies. A separate canonical upload
  source owns the original iterator and stream closer; one retained receive
  operation bounds write observation without cancelling opaque cleanup.
  Original upload errors survive recipient protocol-error conversion, and
  write-deadline cleanup debt remains attached to the exact original owners.
- Give native PostgreSQL test scopes access to the actual pgvector extension
  schema and retire migration-test databases within their own fixture lifetimes.

This is not completed Frinz adoption, catalog LoRA training/selfie acceptance,
private Ollama startup, paid Runpod/Kite testing, actual GPU cost evidence, or a
fix for the separate late-worker warnings tracked by #3734. Private Frinz and
catalog contracts are not public package releases.
