# 0.66.13 — Native hosted peer admission

- Hosts that explicitly select local native A2A can match the original
  in-process sender publication to the standard signed SDK request. The
  original source and recipient authorities remain bound over the effect
  or read. Task ownership still records the authorized principal.
- Task cancellation and Peer Stop may use a hosted control lease only after
  signature and replay checks. Committed cancellation wakes existing streams
  even while ordinary projections wait; stream reads still use the ordinary
  guarded path. The control lease is released before ordinary projections
  run under their original owner.
- Read-only subscriptions retire their original stream before a refusal.
  A response failure after a committed write still carries that outcome.

The wire format and stored task schema do not change.
See [Core #4164](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4164).
