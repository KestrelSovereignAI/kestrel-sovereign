# 0.66.12 — Scheduler shutdown and Cloud Run rollout settings

- Scheduler shutdown joins the original workers and pending telemetry
  publication. It starts the optional stopped-status write only while its
  work admission remains live. Known retirement skips that write, and
  uncertainty and prior failures still reach the caller.
- The standard Cloud Run test profile preserves the signed Constitution
  source, descriptor, Sovereign root, and audit credential versions. The
  deployer adopts the three existing manual mounts when their file paths,
  volume names and pinned secret references match the tracked profile.

See [Core #4233](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4233)
and [Core #4231](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4231).
