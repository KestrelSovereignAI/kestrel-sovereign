# 0.66.5 — explicitly isolated standalone native bootstrap

Candidate release notes; publication, deployment health and downstream
acceptance remain separate gates.

- Explicit `KESTREL_A2A_PEER_POLICY=isolated` installs the canonical deny-all
  peer directory and empty, non-federating DID resolver in the standalone
  native publication factory. The production profile selects this policy;
  missing peer configuration never selects it implicitly.
- Server and direct library entrypoints use the same construction. The live
  Peers feature is the authoritative directory owner, with no stale constructor
  fallback. Native runtime checks retain the original owner and policy binding.
- Invalid policy names, conflicting injected/host/federation configuration and
  standalone policy on fleet entrypoints refuse startup. Existing explicit
  policies remain unchanged when the isolated setting is absent.
- Preserve signed native discovery, original identity/database custody,
  runtime readiness, full streaming and physical lifecycle retirement. Isolation
  trusts no inbound sender or outbound peer; it does not disable publication or
  create replacement execution authority.
- Close three test-owned SQLite handles deterministically while preserving
  their transaction context. No production garbage-collection fallback or
  warning suppression is added.

Source fix: [#4166](https://github.com/KestrelSovereignAI/kestrel-sovereign/pull/4166),
for [#4162](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4162).
The database upgrade and secret repair are independent of this source fix.
Production [#3340](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/3340)
is complete only after an exact released artifact passes actual health,
original-DID and deliberate serving verification.

This release does not resolve the original host-resource lending gap in
[#4164](https://github.com/KestrelSovereignAI/kestrel-sovereign/issues/4164),
complete Frinz catalog adoption, or establish live LoRA/Ollama/Kite acceptance,
GPU cold-start time or cost. Private Frinz/catalog packages are not public
package releases.
