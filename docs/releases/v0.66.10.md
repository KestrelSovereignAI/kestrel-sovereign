# 0.66.10 — Public A2A Agent Cards

- Use the registered ML-DSA-65 multicodec when publishing DID verification
  methods. Continue reading historical keys so existing identities can verify.
- Publish signed A2A Agent Cards for the two Cloud Run DEV demo agents. Both
  JSON-RPC and HTTP+JSON use the advertised public URLs and tenant routes.
- Verify the expected issuer before consuming an MCP OAuth callback. Update
  the MCP integration to MCP Feature 0.24.0.
- Ship the published second-edition Kestrel Constitution and voluntary pledge.
  Direct the default system prompt to the agent's governing text.
- Queue each isolated Kite inference approval for the exact prepared request
  and allow it to be consumed once.
- Allow operators to pause automatic production rollout while Core releases
  continue to publish and deploy DEV.

Integration testing used the live Crystallize connector. A new Core process
restored its stored grant, refreshed both tokens, and executed a tool from the
App in chat.
