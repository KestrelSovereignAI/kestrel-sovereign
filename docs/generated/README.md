# Generated Documentation

This directory holds checked-in generated documentation artifacts.

## Feature Docs

The audience feature docs are derived artifacts generated from the canonical feature inventory at [`KESTREL_FEATURES.md`](../../KESTREL_FEATURES.md).

Rules:

- Do not edit generated audience docs manually.
- Regenerate them from the canonical source.
- If the generated output is wrong, fix the canonical source or the generator prompts.
- Check metadata with `uv run python scripts/generate_feature_docs.py --check`.

Audience prose is an LLM transformation and therefore cannot be regenerated
byte-for-byte in CI: it requires an external provider credential/model and
records the generation time and selected model. Package ownership is different.
The canonical protected boundary section is inserted verbatim by the generator,
and `--check` deterministically rejects a missing/stale section or prose that
promotes a named extracted Feature, provider, or standalone surface to bundled
status. CI can therefore enforce ownership even though it cannot reproduce the
surrounding audience prose.

Files:

- [`FEATURES_developer.md`](FEATURES_developer.md)
- [`FEATURES_user.md`](FEATURES_user.md)
- [`FEATURES_investor.md`](FEATURES_investor.md)

## Demo Evidence

- [`DEMO_EVIDENCE.md`](DEMO_EVIDENCE.md) is generated from `demos/*/demo.cjs` and `demos/*/eye.toml`.
- Regenerate it with `uv run python scripts/generate_demo_evidence_docs.py`.
- Check it in CI with `uv run python scripts/generate_demo_evidence_docs.py --check`.

## Verification Surfaces

- [`DOC_VERIFICATION.md`](DOC_VERIFICATION.md) is generated by `uv run python scripts/docs_verify.py audit`.
- [`RENDER_MANIFEST.json`](RENDER_MANIFEST.json) is generated by `uv run python scripts/docs_verify.py manifest`.
- The ledger tracks OKF docs, local links, code/file references, render routing, and relevant recent merged PRs.
- The manifest gives Mintlify/Starlight-style renderers a machine-readable public/internal/archive/exclude route list.
- Check both with `uv run python scripts/docs_verify.py audit --check` and `uv run python scripts/docs_verify.py manifest --check`.

## OKF Views

- [`index.md`](index.md) is generated by `uv run python scripts/docs_okf.py index`.
- [`log.md`](log.md) is generated by `uv run python scripts/docs_okf.py log`.
- Check both with `uv run python scripts/docs_okf.py index --check` and `uv run python scripts/docs_okf.py log --check`.
